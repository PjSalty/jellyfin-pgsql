# Cache classification for every table in the EF model. The schema-drift CI
# job extracts table names from the assembled ModelSnapshot and fails if any
# table is missing here (or listed here but gone from the model): an upstream
# schema change must be classified by a human before it ships, because the
# interceptor caches everything not explicitly excluded.
#
# policy values:
#   cached    read-heavy browse/playback data; invalidated on write, 30m TTL
#   excluded  security-relevant or insert-heavy; every read hits postgres
#
# An "excluded" row here MUST also appear in DefaultExcludedTables in
# overlay/Jellyfin.Plugin.Pgsql/Cache/ValkeyCacheConfig.cs; the CI job checks
# the two stay in lockstep.
